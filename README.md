# 🤖 MultiAgentBot

> **A Gemini-powered Multi-Agent AI system that decomposes tasks, researches solutions, generates implementations, and reviews the final output.**

## 📌 Overview

**MultiAgentBot** is a multi-agent artificial intelligence system built using **Python, Google Gemini API, and Streamlit**.

The system uses multiple specialized AI agents instead of relying on a single agent to handle the complete task. Each agent performs a specific stage of the workflow, and the output of one agent is passed to the next.

### 🔄 Workflow

```text
User Task
    ↓
🧠 Planner Agent
    ↓
🔍 Researcher Agent
    ↓
💻 Coder Agent
    ↓
🧪 Reviewer Agent
    ↓
📊 Final Evaluation
```

The current system consists of four specialized agents:

| Agent         | Role                                       |
| ------------- | ------------------------------------------ |
| 🧠 Planner    | Breaks the task into structured steps      |
| 🔍 Researcher | Identifies concepts, algorithms, and tools |
| 💻 Coder      | Generates implementation details or code   |
| 🧪 Reviewer   | Evaluates the generated solution           |

# 🧠 Agent Architecture

## 1. 🧠 Planner Agent

The Planner Agent receives the user's task and converts it into a clear, numbered execution plan.

For example:

```text
User Task:
Build a student management system
```

The Planner may generate:

```text
1. Define system requirements
2. Design the database
3. Create the backend
4. Implement CRUD operations
5. Add validation
6. Test the application
```

The Planner's prompt specifically instructs Gemini to act as an AI planner and break the task into clear numbered steps.

---

## 2. 🔍 Researcher Agent

The Researcher Agent receives the plan generated by the Planner.

It analyzes the plan and identifies:

* Important concepts
* Algorithms
* Tools
* Technologies
* Implementation approaches

Its role is to provide the technical information required by the Coder Agent.

---

## 3. 💻 Coder Agent

The Coder Agent receives the Researcher's output and converts the research into implementation-level details or code.

It is designed to act as an expert software engineer and use the research to create an implementation.

---

## 4. 🧪 Reviewer Agent

The Reviewer Agent evaluates the solution generated by the Coder.

It produces three evaluation metrics:

```text
QUALITY_SCORE
CONFIDENCE_SCORE
READINESS_SCORE
```

Each score is represented on a **0–100 scale**.

The reviewer also provides:

* Strengths
* Weaknesses
* Final review

The application then displays these scores and the detailed review.

# 🔗 How Agents Communicate

MultiAgentBot currently follows a sequential workflow.

The output of each stage becomes the input for the next stage:

```text
Task
 ↓
Planner
 ↓
Plan
 ↓
Researcher
 ↓
Research
 ↓
Coder
 ↓
Solution
 ↓
Reviewer
 ↓
Evaluation
```

The command-line implementation directly follows this pipeline by passing the Planner output to the Researcher, Research output to the Coder, and generated solution to the Reviewer.

# 🤖 Gemini API Integration

MultiAgentBot uses Google's `google-genai` package for communication with Gemini.

The Gemini client loads the API key using `python-dotenv`:

```python
load_dotenv()
```

and initializes the Gemini client using:

```python
client = genai.Client(
    api_key=os.getenv("GOOGLE_API_KEY")
)
```

The current Gemini model configured in the project is:

```text
models/gemini-flash-latest
```

# 🔐 Environment Variables

Create a `.env` file in the root directory:


# 🧠 Shared Memory

The project contains a simple `SharedMemory` implementation.

It stores information using key-value pairs:

```python
memory.save("key", value)
```

and retrieves it using:

```python
memory.get("key")
```

The current implementation uses an in-memory Python dictionary as the storage mechanism.
